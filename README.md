# 🇧🇷 Brazilian E-Commerce Analytics (Olist Pipeline)

An end-to-end data analytics project using **Python**, **SQL**, **Power BI**, and **Excel** to analyze 100k e-commerce orders from Olist (2016–2018).

---

## 📌 Project Architecture & Workflow
1. **Data Preprocessing (Python / Google Colab):** Cleaned, merged, and translated Portuguese product categories.
2. **Database Analytics (SQL):** Ingested data into SQL schema to execute business queries on logistics, payments, and revenue.
3. **Interactive BI Dashboard (Power BI):** Modeled data in Star Schema and built key performance measures using DAX.

---

## 📁 Repository Structure
* `/data`: Dataset download instructions & cleaned dataset details.
* `/notebooks`: Google Colab Python notebooks for cleaning and EDA.
* `/sql`: SQL setup scripts and analytical queries.
* `/dashboard`: Power BI `.pbix` file and report screenshots.
* `/notes`: Learning notes, rationale behind choices, and interview prep.

---

## 📊 Key Business Insights
* **Delivery Performance:** On-time deliveries maintain an average review score of **4.3/5**, whereas delayed deliveries drop to **1.6/5**.
* **Payment Preferences:** Credit cards dominate **737%** of total transaction value, followed by Boleto (~19%).
* **Regional Disparities:** São Paulo (SP) generates over **40%** of order volume, with significantly lower freight costs than northern states.
